# Causal Inference Lab
Laboratorio di Inferenza Causale interattivo per la formazione docenti.

## Come eseguire localmente:
1. Crea un virtual environment: `python3 -m venv venv`
2. Attiva: `source venv/bin/activate`
3. Installa: `pip install -r requirements.txt`
4. Esegui: `streamlit run app.py`
